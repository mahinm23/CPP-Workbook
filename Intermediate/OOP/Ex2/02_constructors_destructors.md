# OOP 02: Constructors and Destructors

## Exercise
1. Rewrite `Trade`'s constructor to use a member initializer list.
2. Add a destructor that prints "Trade destroyed" when a `Trade` object is destroyed.
3. In `main()`, create a `Trade` inside a nested block `{ ... }` and print something right after the block ends, so you can see the destructor fire at the right moment.

## Starter
Create your own `02_constructors_destructors.cpp` in this folder. Headers you'll need:
```cpp

```
